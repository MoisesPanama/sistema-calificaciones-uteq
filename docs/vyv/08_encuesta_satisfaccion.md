# Encuesta de Satisfacción

> **Asignatura:** Verificación y Validación de Software — UTEQ
> La encuesta se diseñó en **Google Forms** (formato exportable a PDF). Respuestas **simuladas** con base en la prueba Beta (6 participantes).

---

## Formulario de encuesta

**Título:** Encuesta de satisfacción — Sistema de Registro de Calificaciones UTEQ

**Preguntas (escala Likert 1–5, donde 1 = Totalmente en desacuerdo, 5 = Totalmente de acuerdo):**

| # | Pregunta |
|---|---|
| P1 | El sistema es fácil de usar (facilidad de uso) |
| P2 | La información de calificaciones es precisa y confiable (confiabilidad) |
| P3 | El diseño y la navegación son agradables (apariencia) |
| P4 | La velocidad de respuesta es adecuada (rendimiento) |
| P5 | Encontré la información que necesitaba sin ayuda (utilidad) |
| P6 | Recomendaría este sistema a otros establecimientos (recomendación) |
| P7 | Pregunta abierta: ¿Qué mejorarías del sistema? |

## Resultado global

| Métrica | Valor |
|---|---|
| Promedio general de satisfacción | **4.7 / 5** |
| Dimensión mejor valorada | Confiabilidad (P2) = 5.0 |
| Dimensión con mayor margen de mejora | Apariencia (P3) = 4.2 |
| Porción de participantes satisfechos (≥4.5) | 5 de 6 (83%) |

**Interpretación:** la satisfacción global es alta (94%). La confiabilidad es el punto más fuerte; la apariencia y algunas sugerencias de usabilidad (móvil, planillas exportables, gráficos) representan oportunidades de mejora para una siguiente iteración.
